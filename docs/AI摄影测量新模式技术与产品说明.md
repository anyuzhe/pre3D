# AI 摄影测量新模式：技术、操作与产品说明

## 1. 结论

当前产品采用“AI 局部特征匹配 + 传统摄影测量”的混合路线：

```text
原始高分辨率照片
→ 照片质检与关键帧
→ ALIKED / SIFT 局部特征
→ LightGlue 照片匹配
→ 两视图几何验证
→ GLOMAP / COLMAP SfM
→ 全局 Bundle Adjustment
→ 原图去畸变
→ PatchMatch Stereo
→ 深度融合
→ 稠密点云
→ 标尺 / 控制点 / 检查点
→ 工程成果
```

这条路线的核心不是让 AI 直接“猜出最终点云”，而是让 AI 专门解决传统摄影测量最容易失败的照片对应问题，再由成熟的多视几何负责相机、三维结构、一致性优化和稠密重建。

## 2. 每一个阶段具体怎么做

### 2.1 工程和原始照片管理

软件把工程元数据、原始照片列表、关键帧列表、运行参数、阶段状态、标定和测量记录写入 `project.json`。原照片不会被修改。

若照片来自多个目录，摄影测量运行目录会为本次任务建立一个只包含当前照片集合的隔离目录。照片集合和参数都有指纹；换照片或改关键参数时，新任务不会错误复用旧数据库。

### 2.2 照片质量扫描

对每张照片读取：

- 宽高和百万像素；
- EXIF 拍摄信息；
- 焦距、机型和镜头信息；
- 拉普拉斯清晰度；
- 文件哈希和缩略图感知特征。

作用：

- 排除完全重复照片；
- 默认排除价值很低的近重复照片；
- 发现严重模糊、镜头/焦距切换和异常图像；
- 减少无效匹配数量和 MVS 计算量。

这一步不是重建，也不是精度认证。它是进入昂贵 GPU 任务前的质量门检。

### 2.3 拍摄连续性与关键帧

软件分析相邻照片的可匹配程度，把明显断开的序列标出来。启用自动分段时，会优先保留最长、可连续连接的照片段。

关键帧不是越少越好，也不是越多越好：

- 太少：基线过大，相邻照片找不到稳定对应；
- 太多且近乎重复：匹配和 MVS 很慢，几何信息增加很少；
- 合适：每个表面被多张照片从不同位置看到，同时相邻变化连续。

### 2.4 ALIKED‑N16Rot 特征提取（推荐）

ALIKED 在原始照片上寻找可重复定位的关键点，并为每个点计算描述子。描述子用于判断另一张照片中的某个点是否来自同一实体位置。

软件使用 `ALIKED_N16ROT` ONNX 模型。`N16Rot` 是兼顾速度、旋转适应性和描述能力的默认方案，适合：

- 岩面和边坡的细碎纹理；
- 视角、亮度发生变化；
- 普通 SIFT 只能注册部分照片；
- 手机或无人机拍摄的较大照片集。

关键参数：

- “AI特征最大边长”：控制特征阶段输入分辨率；
- “每图最大特征数”：控制每张图保留的关键点上限。

提高两项通常能增加困难区域的可匹配点，但会增加 GPU/CPU 时间、数据库体积和匹配成本。

### 2.5 SIFT + LightGlue（兼容备选）

这个模式使用传统 SIFT 提取关键点和描述子，但不用传统最近邻规则完成最终匹配，而是交给 LightGlue。

适用情况：

- ALIKED 在某个特殊材质上不稳定；
- 希望使用更成熟、可解释的 SIFT 检测结果；
- 需要为项目保留第二套独立匹配方案；
- 排查“特征提取失败”还是“几何失败”。

它不是简单的“低级模式”。在某些高对比、纹理稳定、尺度变化明显的照片中，SIFT 仍可能更稳。

### 2.6 LightGlue 照片匹配

LightGlue 的输入是两张照片各自的关键点和描述子，输出两张照片之间的对应点索引。它会利用点集上下文排除大量“外观看起来相似但几何上不可信”的候选。

本产品中 AI 到这里为止：AI 只提出更可靠的照片对应，不直接决定最终相机位姿或点云坐标。

匹配后还会进行两视图几何验证。只有能被基础矩阵/本质矩阵等几何模型支持的对应，才进入 SfM 视图图。

### 2.7 三种照片配对模式

#### 自动选择

- 120 张及以下：全连接匹配；
- 超过 120 张：顺序匹配。

这是通用默认值。

#### 全连接匹配

每张照片与其他所有照片尝试匹配。

适合：

- 3～120 张；
- 照片顺序被打乱；
- 围绕物体多圈拍摄；
- 不确定哪些照片相邻；
- 小型边坡、岩样、建筑立面。

代价近似随照片对数量二次增长。几百张照片使用全连接会非常慢，也会生成大量没有重叠的无效照片对。

#### 顺序匹配

每张照片只和前后一定窗口内的照片匹配，并启用扩大范围的顺序连接。

适合：

- 隧道连续拍摄；
- 沿边坡、道路、廊道按顺序移动；
- 视频抽帧；
- 100～500 张以上的有序照片。

“顺序匹配前后窗口”默认 20。窗口太小可能跨不过拍摄跳变；太大则增加时间。存在回环时，需要确保回环附近照片仍能建立连接；后续产品可再增加图像检索配对模式。

### 2.8 GLOMAP 全局 SfM（推荐）

全局 SfM 在照片视图图上联合估计全局旋转、位置和三维结构，然后进入几何优化。

优点：

- 大照片集通常更快；
- 不强依赖从哪张照片开始；
- 对环绕拍摄和多方向照片更自然；
- 全局处理有利于抑制长序列逐步累积的姿态误差。

当前 GLOMAP 功能已经迁入 COLMAP，并通过 `global_mapper` 使用。软件不依赖旧的独立 GLOMAP 可执行程序。

失败时常见原因：

- 匹配图被分成多个不连通分量；
- 共享内参设置错误；
- 焦距初值严重错误；
- 重复纹理产生错误闭环；
- 照片几乎原地旋转、缺少平移基线。

### 2.9 COLMAP 增量 SfM（兼容备选）

增量 SfM 先选择一对可靠照片初始化，再逐张注册照片，并周期性优化。

适合：

- 中小项目；
- 全局 SfM 在当前数据上初始化失败；
- 需要用另一套求解顺序交叉验证；
- 照片连接呈明确的逐段增长结构。

它可能比全局模式慢，也可能受初始照片对影响，但在某些数据上能注册更多照片。因此产品保留两种求解器，而不是把成功率押在单一算法上。

### 2.10 相机模型和共享内参

默认 `SIMPLE_RADIAL`：

- 一个焦距；
- 主点；
- 一个径向畸变参数；
- 对普通手机、相机和无人机通常是稳妥起点。

其他模式：

| 模式 | 适用情况 | 风险 |
|---|---|---|
| SIMPLE_PINHOLE | 已校正或畸变很小 | 广角镜头容易残留畸变 |
| PINHOLE | 需要分别估计 fx、fy | 参数更多，弱几何时不稳 |
| SIMPLE_RADIAL | 普通项目默认 | 极广角可能不足 |
| RADIAL | 需要两个径向参数 | 数据不足时参数相关 |
| OPENCV | 已知需要更完整畸变 | 参数最多，需要更强约束 |

“共享一组内参”只应在以下条件同时满足时启用：

- 全部照片来自同一物理相机；
- 同一镜头；
- 拍摄中没有光学变焦；
- 没有混用主摄、长焦、超广角；
- 没有分辨率/裁切模式切换。

只要混用镜头或变焦，就应取消共享，或先按相机分组处理。错误共享内参会让 BA 用扭曲几何去迁就不一致照片。

### 2.11 Bundle Adjustment

BA 联合优化：

- 所有已注册相机的旋转和平移；
- 相机内参和畸变参数；
- 稀疏三维点；
- 观测重投影误差。

它是新路线比直接点图更适合工程产品的关键：每个三维点必须能够通过相机模型投回原照片，并尽量落在实际观测的特征位置上。错误匹配会被几何验证和鲁棒优化进一步抑制。

BA 成功不等于绝对尺度正确。没有标尺、RTK/PPK 或控制点时，SfM 仍是任意尺度。

### 2.12 原图去畸变

BA 完成后，软件使用优化后的相机模型重新采样原始高分辨率照片，生成去畸变 MVS 工作区。

这一步确保稠密深度计算使用：

- 原照片细节；
- 优化后的相机姿态；
- 优化后的内参和畸变；
- 统一的针孔几何。

### 2.13 CUDA PatchMatch Stereo

全部合格照片先参加 SfM；空三完成后，全部成功注册的照片均作为 MVS 参考帧
生成完整深度图。快速预览、标准工程和高精度三档都固定为100%参考帧。

三档速度差异只来自图像分辨率、几何一致性、源照片数量和迭代次数，不再通过
删除参考深度图换取速度。这能更稳妥地保留坡顶、坡脚、左右边缘、遮挡转折和
斜视照片独有的表面覆盖。100%参考帧不能弥补拍摄盲区，但避免软件主动丢弃
已经成功注册的有效视图。

PatchMatch 对每个参考视图计算稠密深度和法向，并使用邻近照片进行光度和
几何一致性验证。界面解析 COLMAP 的 `Processing view X / Y` 输出，分别显示
光度深度和几何一致性阶段的真实参考帧进度，不再把长时间 GPU 计算误显示为卡死。

“MVS 最大图像尺寸”直接影响最终点云细节、耗时、显存和磁盘：

- 2048：快速试跑；
- 3200～4096：普通工程默认；
- 接近原图尺寸：高细节终版，但成本显著增加。

照片数量只能增加视角和约束，不能自动恢复原图已经丢失的像素细节。最终可分辨能力首先受物面分辨率、对焦、运动模糊和拍摄距离限制。

在启动 PatchMatch 前还有空三质量闸门：

- 推荐注册照片比例至少 95%；
- 推荐平均重投影误差不高于 2 px；
- 检查稀疏点数量是否足以支持当前注册照片；
- 严重不合格时阻止稠密重建，临界结果要求人工检查相机轨迹和稀疏覆盖。

这是“避免无效计算”的闸门，不是把阈值包装成工程精度认证。

### 2.14 深度融合

`stereo_fusion` 把多个视图的几何一致深度融合成一个彩色稠密点云。当前产品输出 PLY，并保留：

- BA 稀疏模型；
- 原始融合 PLY；
- 最终产品 PLY；
- 注册照片数量与比例；
- 匹配照片对数量；
- 完整日志和阶段状态。

### 2.15 标尺、控制点和检查点

重建完成后，点云仍处于 SfM 模型单位。

#### 标尺模式

在三维点云拾取一段已知真实距离：

```text
比例 = 实际距离 / 模型距离
```

多个不同位置的标尺会共同拟合统一比例，并能暴露粗差。它只解决统一尺度，不保证大型场景没有局部形变。

#### 工程坐标模式

在点云中拾取控制点，输入对应 XYZ：

- 至少 3 个不共线点才能求解；
- 工程建议 5～8 个以上；
- 四周、中部、高处、低处都要覆盖；
- 另留 2～4 个检查点，不能参与拟合。

系统拟合七参数相似变换：尺度、三维旋转和平移。

#### 检查点

检查点只用于计算独立残差。控制点拟合残差很小，不代表远端也准确。产品报告以检查点 RMSE 和最大误差作为最重要的绝对精度证据。

### 2.16 点云过滤

新 MVS PLY 没有直接点图模型的逐点 AI 置信度，所以界面不再提供旧“置信度分位过滤”。当前过滤链为：

1. 删除 NaN/Inf；
2. 可选全局距离 MAD 粗离群；
3. 可选体素降采样；
4. 可选统计离群点过滤；
5. 可选半径邻域过滤；
6. 保存过滤缓存和 PLY。

建议先保守过滤。岩体薄棱、裂隙边缘和孤立小构件可能被强半径过滤误删。

## 3. 断点恢复和崩溃隔离

照片扫描、AI 摄影测量和点云过滤均在独立子进程运行。主界面不直接承载高风险 GPU 推理。

好处：

- COLMAP 或 ONNX/CUDA 崩溃不会直接破坏 Qt 主界面；
- 用户可取消当前任务；
- 主界面持续显示 GPU 显存与利用率；
- 每阶段状态写入 `pipeline_state.json`；
- 已完成且通过完整性检查的阶段可直接恢复。

阶段包括：

```text
ai_feature_extraction
ai_feature_matching
sparse_mapping
bundle_adjustment
sparse_output（生成空三检查点云、相机位姿和质量统计）
image_undistortion
patch_match
stereo_fusion
pointcloud_output（写出 SfM 原生点云和元数据）
```

专业模式可以在 `sparse_output` 后暂停，由用户检查注册率、未注册照片、
重投影误差、相机位置与稀疏点云。默认一键模式则自动执行质量闸门：推荐路线
不合格时先回退到 SIFT + LightGlue + COLMAP 增量 SfM；回退路线通过后自动
继续去畸变、PatchMatch、融合和最终点云写出。只有两条路线都不合格时才停止。

PatchMatch 深度文件会检查头部、尺寸和预期字节数。崩溃留下的半文件会被删除，避免下一次把损坏缓存当作完成结果。

稀疏与稠密缓存使用不同参数指纹。改变 MVS 尺寸、几何一致性、源照片数、
迭代次数或深度过滤，只创建新的 `dense_<参数指纹>` 工作区；特征、匹配、
SfM 和 BA 不会重复。快速预览和终版可并存，也能分别断点恢复。

## 3.1 面向普通用户的自动封装

默认产品界面只暴露“项目、一键重建、成果”三个页面。用户只选择快速预览、
标准工程或高精度模式，不直接选择特征、匹配、SfM、相机和 MVS 参数。

```text
导入照片
→ 选择成果精度
→ 一键重建
→ 自动质检
→ ALIKED + LightGlue + GLOMAP
→ 质量不足时自动回退 SIFT + LightGlue + COLMAP 增量 SfM
→ 全部注册照片进行 MVS
→ 自动打开成果
```

专业页面没有删除，可从“高级功能”菜单展开，用于问题诊断、自定义参数、标尺、
控制点、检查点和高级过滤。这样同一套计算核心既能服务第一次使用的现场人员，
也能保留工程人员需要的可诊断性。

## 4. 为什么 VGG‑T³ 在这个产品中表现不好

### 4.1 它解决的是“快速前馈重建”，不是“工程摄影测量闭环”

VGG‑T³ 的研究目标是让大量无位姿照片能够快速、线性规模地完成前馈点图、深度和相机预测。这个目标本身有价值，但和本产品最终需要的高分辨率、可测量、可检查、可追溯工程点云并不相同。

### 4.2 相机姿态误差会整体污染点云

直接点图需要网络同时预测相机姿态、内参、深度和点图。相机姿态稍有系统误差，多个视图就会出现双层、扭曲、墙面撕裂、远端漂移和“展开图”效果。

VGG‑T³ 论文自己的标准基准分析明确指出，TTT 线性化模型在相机姿态估计上存在困难；论文也把宽基线场景的精度差距列为限制。这与实际测试中“局部看着像，整体拼不稳”一致。

### 4.3 网络输入长边约 518 像素

论文训练和推理体系把长边缩放到 518。若一张照片横向覆盖 30 米，则仅按像素估算：

```text
30 / 518 ≈ 5.8 厘米/像素
```

原图可能有 4000～8000 像素，但直接点图阶段无法完整保留这些细节。增加照片数量能增强视角约束，却不能把每张图被缩掉的高频纹理重新变成毫米级裂隙。

新路线只在特征阶段按参数缩放；最终 MVS 会回到原始高分辨率照片。

### 4.4 深度指标通常经过尺度对齐

论文中的视频深度评估对每段序列执行单一尺度对齐。这说明模型输出本身不是天然米制。即使视觉形状合理，也不能直接声称长度、面积或体积具有工程单位。

### 4.5 缺少工程化的显式残差闭环

直接网络输出不天然提供传统摄影测量中的完整链条：

- 哪两张照片匹配；
- 有多少几何内点；
- 哪些照片被注册；
- 每个特征的重投影误差；
- BA 是否收敛；
- 哪些照片进入 MVS；
- 哪些深度通过多视一致性。

工程产品不仅需要一个“看起来像”的点云，还需要失败可诊断、参数可复现、成果可验收。

### 4.6 对拍摄质量仍有要求

前馈模型可以在低重叠或弱纹理下给出某种预测，但这不代表预测一定是现场真实几何。没有共同可见区域、严重反光、完全重复纹理、运动模糊和只原地旋转，都会让问题缺少充分物理约束。

## 5. 为什么新模式更适合产品

| 产品要求 | 直接前馈点图 | AI 特征 + 传统摄影测量 |
|---|---|---|
| 原图细节 | 受固定网络输入分辨率限制 | MVS 使用原始高分辨率照片 |
| 匹配困难 | 学习先验较强 | ALIKED/LightGlue 专门增强 |
| 相机几何 | 网络直接回归 | 两视图几何 + SfM + BA |
| 大场景一致性 | 姿态误差可能直接进入点图 | 全局/增量 SfM + 全局 BA |
| 可诊断性 | 中间几何证据有限 | 匹配、注册率、稀疏模型、日志完整 |
| 断点恢复 | 模型级缓存 | 每个摄影测量阶段独立恢复 |
| 控制点/标尺 | 需要额外映射 | 可在最终 MVS 点云统一标定 |
| 工程坐标 | 非原生目标 | 相似变换与检查点报告清晰 |
| 产品替换性 | 功能押在单一大模型 | 特征、匹配、SfM、MVS可分别升级 |
| 商业维护 | 大模型权重和显存负担大 | 本地模型小，传统几何生态成熟 |

更重要的是，这条路线允许产品逐步升级：

- ALIKED 可替换为其他局部特征；
- LightGlue 可升级或加入其他匹配器；
- 全连接/顺序可增加图像检索配对；
- GLOMAP 与增量 COLMAP 可交叉回退；
- MVS 可替换为 OpenMVS 或其他高分辨率稠密算法；
- 控制点可进一步直接进入 BA，而不只是结果后相似变换。

这是一套可组合的工程平台，而不是一个模型的演示壳。

## 6. 推荐模式

### 6.1 普通边坡，30～120 张

```text
ALIKED + LightGlue
全连接匹配
GLOMAP 全局 SfM
SIMPLE_RADIAL
同一镜头则共享内参
特征 4096
MVS 3200～4096
```

### 6.2 隧道/道路连续拍摄，100～500 张

```text
ALIKED + LightGlue
顺序匹配
窗口 20～40
GLOMAP 全局 SfM
形成回环时保留回环附近照片
先用 MVS 2048 试跑，再用 4096 终版
```

### 6.3 照片无序、角度变化较大

```text
ALIKED + LightGlue
中小数据全连接
GLOMAP
提高每图特征数
检查重复纹理导致的错误连接
```

### 6.4 ALIKED 注册率低

依次尝试：

1. 检查照片是否存在真实重叠；
2. 取消错误的共享内参；
3. 提高特征分辨率/数量；
4. ALIKED 改为 SIFT + LightGlue；
5. GLOMAP 改为 COLMAP 增量；
6. 全连接与顺序模式交叉尝试；
7. 删除模糊、反光、镜头切换和断层照片。

### 6.5 快速试跑与终版

快速试跑：

```text
特征最大边 2048～3200
每图特征 2048～4096
MVS 1600～2048
```

终版：

```text
确认注册率和几何正确
特征最大边 4096 或更高
每图特征 4096～8192
MVS 3200～原图尺寸
加入标尺/控制点/检查点
输出精度报告
```

## 7. 重叠率和现场要求

新模式仍需要照片重叠，因为 SfM 和 MVS 必须从多张照片看到的同一实体位置恢复三维。

实践建议：

- 沿行进方向前向重叠约 70%～85%；
- 多排/多高度拍摄时侧向重叠约 50%～70%；
- 纹理弱、反光、远距离或角度变化大时取高值；
- 每个表面至少被 3 张以上清晰照片看到；
- 不只原地转动，必须有适量平移基线；
- 同一区域同时拍正视和斜视；
- 大场景形成回环；
- 固定焦距，不用数码变焦，不混用手机主摄/长焦/超广角；
- 保留 EXIF 和原始照片；
- 快门足够快，避免运动模糊；
- 阴影、反光和动态人员车辆尽量少。

“70% 重叠”不是软件从文件就能精确知道的数值，而是现场路径设计目标。最终应以照片匹配图连通性、注册率和稀疏模型形态判断。

## 8. 精度应如何表述

软件不应承诺“使用某模型就自动达到 2 cm”。

最终精度主要由以下因素共同决定：

- GSD/物面分辨率；
- 清晰度和噪声；
- 相机标定与焦距稳定性；
- 重叠和基线；
- 控制点测量精度与分布；
- BA 重投影质量；
- MVS 分辨率和一致性；
- 独立检查点残差。

产品界面的正确规则是：

- 无标定：只显示模型单位；
- 有标尺：允许米制相对测量，但提示统一尺度的边界；
- 有控制点：进入工程坐标；
- 有独立检查点：才输出绝对误差统计；
- 没有独立检查点：明确写“不能独立评价绝对精度”。
