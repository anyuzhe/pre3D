# 工程坐标与空间分块 MVS

## 工程坐标可靠性

高级功能中的“控制点与检查点”现在支持两类坐标：

- 工程坐标 XYZ：直接输入或导入投影/本地直角坐标；
- WGS84 经纬高：可转换为 Local ENU，也可输入目标 EPSG/CRS 后投影。

WGS84 输入顺序是经度、纬度、椭球高。目标 CRS 留空时，以第一条WGS84
观测作为 Local ENU 原点；填写如 `EPSG:4547` 时，通过 PROJ/pyproj 转换。
高程基准必须由测量人员确认。软件不会把椭球高自动伪装成正常高。

工程标定采用：

```text
RANSAC异常点检测
→ 加权Umeyama七参数相似变换
→ 全部控制点残差复核
→ 独立检查点误差统计
```

控制点CSV支持 `sigma_x/sigma_y/sigma_z`。精度越高的点权重越大。报告输出
X、Y、Z、XY、3D RMSE，中位数、P95、最大误差和被排除的控制点编号。

模板：

- `control_points_template.csv`：工程XYZ；
- `control_points_wgs84_template.csv`：WGS84经纬高。

## 自动空间分块 MVS

照片数量达到设置阈值后，软件不再让全部照片同时生成并保留深度图，而是：

```text
全部合格照片参与全局SfM和BA
→ 读取稀疏点、相机位置和真实共视关系
→ PCA识别长廊/隧道或面状边坡
→ 自动规划Core与Halo
→ 每张注册照片只归属一个Core块并生成一次深度图
→ 相邻Halo照片只作为辅助源图参与匹配
→ 逐块PatchMatch和深度融合
→ 裁切Core，丢弃重复Halo边缘
→ 合并为全局坐标点云
```

全部注册照片都会且只会成为一次参考图；“100%参考帧”要求没有改变。Halo照片
可以在邻块重复提供影像匹配，但不会重复生成深度图，既保护接缝又避免重复GPU计算。
块完成后立即删除该块深度/法向中间图，只保留Core点云和任务记录，因此磁盘峰值
由“全部照片深度图”变为“当前块深度图+最终点云”。

默认设置：

- 启用阈值：180张注册照片；
- 快速预览：每块目标约140张；
- 标准工程：每块目标约120张；
- 高精度：每块目标约90张；
- Halo：20%。

每个块都有独立状态和Core点云。任务中断后，已完成块直接复用，正在计算的块
保留有效深度图继续运行。分块报告位于稠密工作区的
`spatial_blocks/spatial_mvs_report.json`。

报告中的 `total_reference_image_assignments` 应与注册照片数相等；各块的
`reference_images` 不应重复。`image_names` 是更大的Core+Halo源图池，允许跨块重复。

## 适用边界

- 当前GCP仍是结果级鲁棒Sim3，不是把GCP观测直接加入BA；它不能纠正局部形变。
- Local ENU适合项目局部计算；大型跨区域工程应使用正确的投影CRS。
- 分块点云保持全局SfM坐标，可继续执行标尺或控制点转换。
- 当前纹理模型仍是单体模型。超大项目的分块网格、分块纹理和3D Tiles属于下一阶段。
