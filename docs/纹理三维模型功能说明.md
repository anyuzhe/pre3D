# 纹理三维模型功能说明

## 用户怎么使用

在“一键重建”页先选择成果精度，然后在“选择需要的成果”中选择：

- 稠密点云 / 深度图：固定生成，是网格与测量的基础成果；
- 纹理三维模型：可选，勾选后在点云完成后继续自动处理；
- 模型格式：OBJ、FBX、glTF/GLB、OSGB。

如果项目已经有稠密点云，可直接在“成果”页点击“从当前点云生成 / 恢复模型”，
不需要重新执行照片匹配、空三、PatchMatch或深度融合。

## 软件实际执行的阶段

```text
稠密点云 / 深度图
→ 内存映射抽稀、统计离群清理
→ 现有MVS法向归一化、异常法向邻域修复
→ 泊松表面重建
→ 三角网格
→ 退化点/退化面清理、小孔修补、法向一致化
→ 保边界网格简化
→ 按面片空间位置递归划分纹理块
→ 按相机位姿为面片选择原始照片
→ 面片分区和UV展开
→ 每块独立纹理图集打包
→ 原始去畸变照片纹理烘焙
→ 多照片视图选择平滑、全局颜色校正、接缝融合和空白修补
→ 多图集模型组合
→ OBJ / FBX / glTF / GLB / OSGB
```

表面重建、简化和纹理映射由项目自带的COLMAP 4.1.1完成；网格清理、孔洞
修补和法向统一由VTK完成；glTF/GLB由Trimesh写出；OSGB由OpenSceneGraph
`osgconv`真实转换并再次读取验证。

## 三档模型参数

| 模式 | 建模点上限 | 泊松深度 | 目标三角面 | 纹理比例 | 用途 |
|---|---:|---:|---:|---:|---|
| 快速预览 | 200万 | 10 | 25万 | 0.50 | 快速检查表面是否闭合、纹理是否覆盖 |
| 标准工程模式 | 500万 | 11 | 75万 | 0.75 | 默认交付，兼顾细节、体积与查看速度 |
| 高精度模式 | 1000万 | 12 | 150万 | 1.00 | 终版细节模型，耗时、内存和磁盘最高 |

点数上限只作用于表面建模副本，不会降低已经生成和保存的原始稠密点云。软件
还会根据当前可用内存自动下调建模点上限，避免大项目一次性载入数千万点导致
系统崩溃。

纹理阶段不会再把全部面片塞进一张最高65536像素的图集。快速、标准和高精度
模式分别以约8万、10万和12.5万面为一个空间纹理块，每块拥有独立PNG图集。
单块图集最长边限制为32768像素，并限制总像素数；若某个块仍超限或原生纹理
进程在烘焙时内存失败，只降低该块纹理比例并重试，不影响其他块的精度。

## 各格式用途

- OBJ + MTL + PNG：通用交换格式，纹理路径清晰，适合建模和GIS软件；
- FBX：ASCII FBX 7.4，包含顶点、三角面、法向、UV、材质和外部纹理；
- glTF + GLB：适合网页、移动端、Cesium和实时三维；GLB将模型与纹理打包；
- OSGB：适合支持OpenSceneGraph/倾斜摄影OSGB的GIS平台。必须检测到真实
  `osgconv`后才能选择，不会把OBJ改名为OSGB。

当前输出是空间分块、多纹理图集模型。OBJ使用一个组合OBJ/MTL引用全部图集；
glTF/GLB保留多材质；FBX按纹理块写出并附带清单；OSGB从多材质OBJ转换。
超大城市级项目的LOD层级和3D Tiles仍属于后续扩展，当前版本不会把普通模型
伪装成带LOD的倾斜摄影瓦片集。

## 缓存与恢复

模型目录按点云、相机模型和模型参数建立指纹，保存以下阶段：

```text
01_conditioned_points.ply
02_surface_raw.ply
03_mesh_repaired.ply
04_mesh_simplified.ply
05_texture_partitions/block_*/input_mesh.ply
05_textured_blocks/block_*/textured/mesh.ply
05_textured_blocks/block_*/textured/texture.png
05_textured_blocks/texture_manifest.json
06_exports/
pipeline_state.json
model_result.json
model_pipeline.log
```

重新运行时，每一步都会同时检查状态记录和实际文件。只增加一种导出格式时，
直接复用已有点云、网格、UV和纹理图集，只重新执行格式写出。取消任务或外部
程序崩溃不会带崩主界面，重新开始后从最后一个有效阶段继续。

## 质量边界

模型质量不会高于输入点云和拍摄质量。以下情况仍会造成孔洞或拉花：

- 表面没有被照片看到；
- 相邻照片重叠不足，或视角几乎没有基线；
- 反光、水面、透明物体、动态车辆人员；
- 大片纯色、重复纹理、严重阴影变化；
- 空三本身存在相机飞散、折叠或分层；
- MVS深度图已经存在大面积错误。

泊松重建会倾向生成连续表面，因此对开放边坡可能在数据边缘产生薄的封口面。
软件用密度裁剪和小孔尺度限制降低这类问题，但终版工程成果仍应在三维视图检查
边界、背面和遮挡区。
